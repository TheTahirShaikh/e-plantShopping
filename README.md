# Paradise Nursery - e-plantShopping

Paradise Nursery is an online houseplant shop built with React and Redux Toolkit.

## Features
- Landing page with company name and "Get Started" button
- Product listing with 3 categories (6 plants each)
- Add to Cart (button disables after adding), live cart count in navbar
- Cart page with per-item subtotal, total amount, +/- quantity, delete
- Checkout ("Coming Soon") and Continue Shopping buttons

## Tech
React, Redux Toolkit, Vite

## Run locally
npm install
npm run dev
